# 盘迹 · VolumeTrail 0.2.2

Windows x64 便携版，用于记录 NTFS 磁盘空间变化，定位增长目录和文件；无需安装开发工具。

## 已完成功能

- 首次全量建索引，后续通过 USN 日志增量扫描；支持手动扫描、停止和登录后扫描一次。
- 查看空间趋势、目录净变化、文件明细、当前占用排行和按扩展名汇总；支持目录下钻及已删除目录的历史查询。
- CLI 输出文本或 JSON；记录扫描耗时、CPU 和内存，按容量整理历史明细。
- 0.2.2 改进目录移动、文件类型统计、缺失父目录恢复和增量汇总性能，并修复绝对路径、盘符与大小写查询。

## 首次使用与权限

1. 下载并完整解压 `VolumeTrail-0.2.2-windows-x64-portable.zip`，放到有写入权限的固定目录。
2. 双击 `VolumeTrail.exe`，选择 NTFS 磁盘，点击「开始扫描」，接受管理员权限请求，等待首次全量索引完成。
3. 磁盘内容变化后再次扫描，即可比较两次记录；在「设置」中可选择自动扫描的磁盘并开启「登录后扫描一次」。

扫描原始 NTFS 数据需要管理员权限；查看已有记录及 CLI 查询使用普通权限即可。`VolumeTrail-cli.exe` 是命令行入口。配置与记录自动保存在程序旁的 `data/`；迁移时一并保留。程序只记录变化，用户文件由用户自行清理。
