# VolumeTrail 0.2.1

更新日期：2026-10-03。本次验证的便携程序位于 `dist/DiskHistory/`。

## 已交付

- USN 事件先按完整文件标识合并，再读取受影响的 NTFS 记录。文件删除与编号复用分别处理，取消仍回滚本次索引和检查点。
- 目录下钻显示目录净变化、本层变化及子目录变化。本层汇总包含直属文件变化以及记录在该层的整目录移动。
- 历史目录查询与当前索引查询分别返回结果。当前索引没有该目录时，当前大小为 null，历史增长或释放仍可查询。
- 配置中的历史容量上限仅计算文件明细、目录汇总及其索引页。当前文件索引、趋势时间点、性能记录、迁移备份分别显示占用。历史淘汰顺序仍为先明细、后目录汇总，均从最旧记录开始。
- 每次扫描保存读取、提交、整理、总耗时、繁忙暂停时间、事件数、唯一文件标识数、NTFS 读取次数、CPU 用时、整机平均 CPU 占用及扫描进程峰值工作集。记录可在概览的“扫描性能”及 `query summary --json` 查看。
- CPU 与峰值内存来自扫描边界的 Windows 进程计数查询，采集过程没有增加轮询线程。平均 CPU 占用包含暂停时间；内存峰值属于整个扫描进程的生命周期，同一次多盘自动扫描共享该进程峰值。
- 数据库版本为 6，旧时间点的性能字段为 null。升级保留旧扫描内容，只新增性能字段。
