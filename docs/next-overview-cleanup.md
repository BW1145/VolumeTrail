# VolumeTrail 下一版：批准范围与实施记录

批准实施日期：2026-10-21。基线 `9bbe856`，工作分支 `codex/overview-cleanup`。
本文件是用户批准计划的实施约束；阶段记录见文末。未合并、未发布、未替换已安装程序。

## 目标和边界

只改进现有概览，增加用户手动配置的文件清理规则，并同时交付 AI 可用的 CLI。
保留低占用、登录扫描后退出的定位。复用扫描、历史、排行和下钻查询。
不做智能垃圾识别、全盘垃圾扫描、常驻托盘、新调度服务、备份系统、插件框架或事件总线。
已有“历史清理”只管理软件记录，与“文件清理规则”明确区分。

## 概览

在同一个概览依次显示：所选卷剩余空间、最近扫描与相对上次变化；同区间主要增长和减少目录
（各先 3–5 项，可展开）；容量趋势；仅有记录时显示最近清理摘要。
目录必须带必要父路径，长路径中间省略，提供完整路径悬停和复制。
排行点击进入已有详情并保留卷、起止扫描和目录。后台查询，不阻塞筛选和点击。

默认增长区间是“上次操作最终成功点 → 本次清理前点”；清理前后单列。
最新容量和索引使用最近成功核验点。核验与原扫描归为同次操作，可展开真实时间，趋势保留原始观测。
无基线、覆盖不足、扫描失败、核验未完成均表示未知或准确状态，不能当作零。
沿用现有视觉风格、统一间距与单位、数字对齐、增减有符号和颜色，不增加装饰性仪表盘。

## 文件规则

入口：目录/文件详情操作菜单、设置中的文件清理规则。详情入口预填目录，仍须预览和显式启用。
字段：名称、卷身份、明确目录、多文件名通配符、递归（默认否）、最小修改年龄天数、启用状态。
年龄 0 表示不按年龄保留；只删匹配普通文件，不删目录。
首版不加入保留最新 N、容量淘汰和复杂正则。
支持创建、编辑、暂停/启用、删除、预览和立即执行；保存默认禁用。
已启用规则修改范围后先暂停，重新预览才能启用；升级配置不自动启用规则。
预览给出候选、数量、占用估算与跳过原因；实际执行重新验证，规则重叠只处理一次。
直接删除不可撤销，不备份、不进回收站；启用和手动执行都明确展示范围和方式。
取消停止后续文件，已完成删除不回滚。

## 生命周期与一致性

沿用现有登录任务和全局锁，多个卷顺序处理：成功扫描提交真实历史点 → 已启用规则 →
保存结果 → 必要的清理后核验 → 历史整理 → 退出。扫描失败不清理。
同规则每日最多自动执行一次，记录日期、修订和状态；手动扫描仅扫描，手动清理无每日限制。
整个操作仅初始化一次取消标志，核验不能删除或重置用户停止请求。
有删除或结果不确定才核验；没有候选不新增点。
核验复用扫描器，仅允许 RequireIncremental；在 scan_volume 创建 staging 之前检查策略。
日志断档、重置、换卷或其他需要全量的情况立即拒绝，不能静默全盘扫描。
核验成功产生真实关联点并更新游标；下一次增量不能重复记删除。
核验失败显示“文件统计待下次扫描更新”；磁盘实时可用空间单独读并标时间。
CLI growth/folder 默认比较也采用操作分组，显式 from/to 保留物理扫描含义。

## Windows 文件操作

卷身份绑定，拒绝根目录、系统/程序目录、应用程序和数据目录等保护范围。
不跟随联接、符号链接及其他重解析点；删除前检查身份、范围、修改时间、大小、属性。
Windows 操作放独立模块，通过验证后句柄删除，覆盖父目录替换/联接竞态，不使用字符串前缀充当安全边界。
跳过多硬链接、云占位/离线、只读、系统文件；权限、共享冲突、状态变化均跳过。
不提权补救、不改权限、不结束进程或解锁。
所有删除测试仅使用专门创建的临时样本，不启用真实用户目录规则，不修改现有登录任务。

## 最小记录与迁移

记录规则修订摘要、关联扫描、时间、成功/跳过/失败数、占用估算、完成/取消/中断状态。
删除前写 pending，完成后更新；崩溃遗留标记 unknown，下次核验而不重放。
逐项明细有固定上限与期限，裁剪后保留汇总并明确标记。不会复制文件内容或扫描树。
区分删除占用估算与真实可用空间变化。
新增 ui/overview.rs、ui/cleanup.rs、cleanup/、cleanup/windows.rs、独立清理持久化模块。
worker 仅编排，UI 不删文件，所有入口共享匹配与执行逻辑。
配置字段有默认值和原子保存，迁移可重入，旧历史可打开；只提取相关 UI，不做无关重构。

## AI 接口（共同交付要求）

扩展既有 CLI，无 MCP/HTTP 常驻服务。保留旧命令和默认文本输出；机器模式使用带版本契约，
stdout 只有一个 JSON 结果，进度走 stderr，空/失败/部分成功都有稳定错误码与退出状态。
summary/growth 保留 total；folder/largest 补 total 或 has_more；folder 历史子目录正确应用 offset。
类型排行等限额明确截断，输出观测时间、区间与覆盖情况。query 保持只读，不扫描/提权/删除。
capabilities --json 描述版本、命令、读写和权限；完善 help 与自动化文档。
query overview --drive C --json 与 GUI 共用概览服务，提供容量、基线、增减、趋势、最近清理。

清理 CLI 提供规则 list/get/save/edit、preview、enable/pause、execute 和 runs/status。
规则输入为 UTF-8 JSON 文件或 stdin；AI 不直接改数据库/配置。
带修订号的乐观并发控制，过期编辑拒绝。保存禁用，范围变更需再预览启用。
预览返回 plan_id、修订、卷、范围、删除方式、候选数/字节、跳过原因、截断和期限。
一次执行绑定预览对象，只能跳过变化对象，不能扩大到后来文件；自动规则每次重新规划持续范围。
request_id 幂等，重复请求返回原 run_id；状态可随时查询。
GUI、CLI、登录共用服务。访问权、计划编号和修订号不等于用户授权。
AI 流程：概览 → 下钻 → 用户指定规则并预览 → 用户明确同意具体删除/自动范围 → 执行/启用 → 查询汇报。
